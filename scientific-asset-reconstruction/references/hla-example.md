# 案例：肿瘤 HLA 状态与检测方法

来自 HLA 科研插图重建任务的抽象案例。实际素材清单始终以用户本次参考图为准，不固定为某个数量。该案例中应至少考虑以下类别：

| 类别 | 独立元素举例 | 路线 |
|---|---|---|
| 抗原呈递 | HLA-I 重链、β2m、HLA-II α链/β链、TCR 示意、抗原肽、完整分子复合体 | A |
| 基因组 | DNA 双链、突变 DNA、突变星标、单染色体、淡色染色体、X 型染色体、LOH/CNV 示例、结构变异示例 | A/B/C |
| 转录组 | 蓝/绿 RNA 链、ASE 示例、转录抑制示例、独立外显子、正常与异常剪接示意 | B/C |
| 蛋白状态 | 正常、改变、虚线缺失 HLA 图元、单个橙色肽 | A/B |
| 细胞结构 | 空白细胞轮廓、细胞核、带核细胞、单个磷脂、膜片段 | A/C |
| 检测 | 测序仪、测序读段、抗体、蛋白信号方块 | A/B/C |
| 连接 | 不同颜色箭头、虚线箭头（如原图存在） | B/C |

科学审查提醒：HLA-I 的 β2m 不跨膜，HLA-II 的 α/β 链各自跨膜；不能将中央的简化双链图标直接认定为 HLA-I 重链与 β2m。原图的象征性肽图标不等同于真实原子结构。若需精确结构图，应单独核对用户研究目标与可靠结构资料，不私自改写参考图。

## 回归验收场景

1. 用户给 HLA 机制图并要求全部最小图元：列清单，重绘独立蛋白链和各状态，最终不是素材板；输出原生尺寸、透明 PNG 和 ZIP。
2. 用户要求逐张生成：禁止批量板分割替代；工具无法生成时说明。
3. 用户给另一张科研技术路线图：从新图提取样式与元素，不强加 HLA 颜色或生物结构。
4. 用户没有图像生成工具：仅对适合的规则图元做真实矢量重建，并准确披露复杂图元缺失。
