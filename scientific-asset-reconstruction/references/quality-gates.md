# 质量验收与交付规范

| 检查项 | 通过条件 | 失败处理 |
|---|---|---|
| 完整性 | 清单每项有独立文件或明确缺失说明，组合与部件关系可追踪 | 补绘或列明缺失 |
| 原图忠实度 | 轮廓、颜色、比例、视觉风格一致，无新增无关装饰 | 对照参考重新绘制 |
| 科学结构 | 图形含义和标注语义匹配；疑问单独记录 | 人工核对；不静默修正 |
| 透明通道 | 真正 RGBA，`alpha_min()==0` 且有非空主体与透明区域，外边界无实底 | 重新生成或精细处理 |
| 边缘 | 白底、深灰底、棋盘格上均无明显白边、黑边、光晕、邻图残留；虚线与浅色细节完整 | 目视修整或重绘 |
| 画布 | 未非等比缩放，主体完整，留白适当；多余透明留白已裁，保留 3%–5% 安全边 | 用 `trim_assets.py` 等比例裁剪，避免截断 |
| 清晰度 | 报告**有效内容像素尺寸**，而非只报画布；细节足以支持目标排版 | 优先单元素重绘，或让主体充满画面后重生成 |
| 文件 | PNG 可读取、单元对应正确；重复图元仅在确有不同用途时保留 | 修复、去重或记录例外 |
| 矢量 | SVG 为真实路径/形状、非内嵌位图冒充 | 改称 PNG 或重建 |

## 自动与人工检查的区别

`audit_assets.py` 只检查文件事实：模式、Alpha 范围、透明边界、有效 bbox、像素尺寸、完全一致的 RGBA 像素重复项，并生成白底/深灰底/棋盘格三背景预览、`manifest.csv` 骨架和 `quality_report.md` 骨架。Alpha > 0 用于完整内容边界，Alpha >= 16 用于估算有效像素边界（很淡的元素可能低估，须人工复核）。它不验证没有伪棋盘格或不透明内部背景，不识别科学结构、视觉相似性、真正原生分辨率，也不判断近似重复、光晕或细线断裂。自动通过不能替代逐图目视验收。对半透明和虚线元素不得自动判定为低质量。

## 留白与有效尺寸

默认长边目标 1024 px 仅作提醒，可按用途调整；简单箭头、标记可较小，复杂关键元素宜 1024–2048 px 或更高。**画布尺寸不等于有效尺寸**：模型常留大量透明留白（实测出现画布 1149×1369 但有效主体仅 711×964 的情况）。交付前用 `trim_assets.py` 裁留白并重算有效尺寸；若有效长边仍不足，说明原生分辨率不够，应让主体充满画面后重生成或重画，不能靠插值放大冒充高清。

## 推荐交付目录

```
scientific_assets_<figure>_<version>/
  png/<category>/001_element.png
  svg/<category>/001_element.svg  # 可选
  manifest.csv                   # 人工+自动整合的完整清单（见 assets/manifest_template.csv）
  preview.png                    # 有编号及名称；量大时分页
  quality_report.md              # 人工复核、失败和限制
  audit/                         # 可选，机器检查记录（audit.csv/json + 三背景预览）
```

清单中的 `visual_status` / `science_status` 使用 pass / review / fail / not_applicable，未检查填 unknown。区分真实 PNG 检查与生成来源声明。若只完成部分，列出完成数量与待处理条目；不得把未通过的素材标为合格。原图和中间素材板默认不放入最终包，除非用户要求保留。
